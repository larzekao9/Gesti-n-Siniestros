# Expo SDK — versión PINEADA a 54

Este proyecto está **fijado a Expo SDK 54** (RN 0.81 / React 19.1). NO migrar a 56
sin una decisión deliberada: el pin a 54 vino de compatibilidad con Expo Go, pero
el entregable es un **APK standalone** (build local en `C:\dev\siniestros-mobile`,
ver Context.md §6.7.5). Las APIs de Expo cambian entre versiones —
**leé los docs de la versión exacta antes de escribir código:**
https://docs.expo.dev/versions/v54.0.0/
